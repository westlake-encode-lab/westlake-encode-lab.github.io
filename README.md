# Westlake ENCODE Lab

[Lab website](https://westlake-encode-lab.github.io/)

- **Edit:** Update papers, people, news and conference highlights in [content/](content/), the homepage in [templates/home.html](templates/home.html), and photos in [assets/img/](assets/img/).
- **Preview:** With Python 3.12 or newer, run `python3 build.py --preview` and open `_site/preview.html`.
- **Publish:** Push to `main` to deploy via GitHub Actions.
